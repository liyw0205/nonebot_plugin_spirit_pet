# 玩法说明

本文说明当前源码提供的 UID 玩法和指令；对应安装步骤见 [安装教程](INSTALLATION.md)。

命令可带管理员配置的前缀，也可不带，参数前留空格。QQ 群 @ 接入一般先 @机器人，普通群消息需平台另行授权与订阅。按钮以点击者的身份执行，需要参数的入口先填入命令，补齐后再发送。

第一次游玩依次发送：

```text
灵宠领养 青鸾
我的信息
我的灵宠
灵宠帮助
```

领养成功后会显示玩家 UID、初始灵宠和宠物编号，伙伴自动出战。`我的信息` 查看玩家身份与账户，`我的灵宠` 查看出战伙伴的成长状态。然后可以 `灵宠签到`、`灵宠修炼`。旧存档中的伙伴名字仍会正常展示；当前版本不提供修改灵宠名字的用户命令。

帮助按结契、成长、血脉与道具、秘境与关卡、对战与赛季、灵物与灵术、组队与派遣、身份与收集八类组织，可发送 `灵宠帮助 成长` 等分类命令。QQ 原生 Markdown 模式在帮助正文中提供蓝字入口，其他模式仍可手动发送文中的命令。常用页面最多显示四个主要操作按钮；逐行入口挂在该行自身的蓝字上（如秘境“查看详情”、队务“查看详情”、小队“查看名帖”），按钮只保留分页与页面级动作，避免四条上限截断后行入口不可达。

## 结契与灵宠

| 指令 | 作用 |
| --- | --- |
| 灵宠领养 青鸾 | 首次结契，可选青鸾、玄狐、白泽、蛟龙；不填名称则随机初始种族 |
| 灵宠召唤 1 | 每次 100 灵石，支持 1-10 次；十连至少获得一只珍稀灵宠，概率见图鉴 |
| 灵宠每周召唤 | 查看本周免费十连的领取状态；每周一 00:00（北京时间）重置 |
| 灵宠每周召唤领取 | 领取本周免费十连，一次召唤 10 只且不消耗灵石，含同样的珍稀保底 |
| 灵宠列表 1 | 每页 5 只，显示实例编号；“出战”标注同行伙伴，合修可用时提供选择同族伙伴的入口 |
| 灵宠切换 2 | 用列表中的编号切换，同名多宠必须用编号 |
| 灵宠封存 2 | 封存一只非出战、无未结委托的灵宠，释放名册名额但保留成长与配装 |
| 灵宠封存库 1 | 分页查看已封存的灵宠 |
| 灵宠复原 2 | 有空位时将封存灵宠恢复到名册，不会自动出战 |
| 我的灵宠 | 查看境界层数、血脉、属性、资源、连续陪伴记录和下一阶段要求 |
| 灵宠出战 1 2 3 | 设置 1-3 只出战灵宠；同一阵容不能重复宠物种类 |
| 灵宠图鉴 1 / 灵宠图鉴 毕方 | 分页浏览，或查看指定种族的主副属性、天赋和获取途径 |
| 灵宠使用 灵卵名称 1 | 消耗秘境掉落的灵卵，孵化对应种族的新宠 |
| 我的信息 | 查看固定 UID、注册时间、灵石、在册/封存伙伴数与出战数量，不要求出战灵宠 |

每名玩家在同一存档内拥有唯一、固定的数字 UID，从 `10000` 起分配。UID 不是 QQ 号或 OpenID，不随换宠或重启改变，也没有玩家改名指令。`我的信息` 不展示原始平台用户 ID；`我的灵宠`（也可说 `我的宠`）展示出战伙伴资料。后台平台 ID 完全相同才是同一玩家，两端 ID 不同不会自动绑定。

切磋、论剑、入队、邀请、队务和成员管理均填写对方 UID，例如 `灵宠切磋 10001`；也可填写 `UID 10001`。宠物编号、行程编号、战报编号和页码是各自的独立编号，不能用 UID 替代。

新玩家注册时间为首次成功领养时的北京时间，持久保存且不会随重投、查询或重启改变。已有 schema 18 / 19 存档升级到 schema 20 时会先备份、保留数据并分配稳定 UID；只从可核实的首次成功领养回复恢复历史注册时间，记录已过期或有歧义时显示“未记录”。帮助无需结契；未注册使用个人功能时先选择初始伙伴，已有账号缺少出战宠时去名册选择，封存伙伴可先复原。数据库仍保留 `pets.name` 字段以兼容历史存档和战报展示，但不再提供修改入口。

初始选择固定为青鸾、玄狐、白泽、蛟龙，不会随着图鉴扩充而增加。目前共 27 种灵宠，其他种族通过召唤或秘境灵卵获得。图鉴显示各族召唤概率，并标出十连珍稀保底池；标准十连若前九抽未出现玄武、三灵鹿、玄冰蚕、雷泽或霆光雕，第十抽从这五种中按原权重抽取。除付费召唤外，每周还有一次免费十连：`灵宠每周召唤` 查看状态，`灵宠每周召唤领取` 一次召唤 10 只且不消耗灵石，保底规则与付费十连相同；领取标记按本周起始时间保存，下周一 00:00（北京时间）自动失效并重新可领，未领取不会累积。名册已满时领取会被拒绝，且不消耗本周机会。灵卵孵化前会检查在册名额，不足时不消耗；孵化不会自动切换出战宠物。默认在册上限 50 只，封存非出战宠物可释放在册名额，复原则需要空位。封存不删除宠物、装备或技能记录，仍计入收集和成就；封存宠物不参与排行榜。

青鸾偏修炼与风系增伤，玄狐偏首击突袭，白泽带开场护盾，蛟龙擅长破甲。同元素也有不同定位，例如火系玄狐抢攻、毕方强化火系威力、赤焰虎追击残血、熔岩甲受击反震，不是仅替换名称的同一套数值。

## 成长与进化

大境界：启灵 → 凝气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫，每个境界一至十层。

| 指令 | 规则 |

| 灵宠签到 | 北京时间每日 00:00 刷新，默认 200 灵石、3 份灵粮 |
| 灵宠签到奖励 | 查看当前/历史最佳连续天数与签到里程碑 |

| 灵宠培育 3 7 | 让编号 3 与 7 的两只同族伙伴共育一枚该族灵卵，双方各消耗 30 精力并扣除 800 灵石 |

每日首次成功发送 `灵宠签到` 会领取原有基础奖励，并记录一个北京时间签到日。连续签到达到 3、7、14、30 天时，分别解锁一次性里程碑（灵石 100/300/650/1400，并附灵粮、锻灵矿或血脉精华）；在 `灵宠签到奖励` 查看状态并领取，奖励可累积领取。完整错过一个北京时间自然日后当前连续天数归零，但已达成而尚未领取的里程碑仍有效。重复签到仍会被拒绝，同一条重放消息返回原签到回复；签到仍只推进原每日任务，不重复计数。

签到历史从此功能启用后逐日记录。旧存档只保存最近一次签到日期，无法还原更早的连续历史；该日期可用于衔接当前连续天数，但不会据此虚构过去的签到记录。签到日期、基础奖励、每日任务进度与里程碑凭证均在同一事务内保存，不新增数据库表或列。

每日成功发送 `灵宠互动` 会累计玩家级连续陪伴天数，与选中哪只在册灵宠无关。连续 3、7、14、30 天分别可领取 80/180/420/1000 灵石，并附灵粮、同心丹、锻灵矿或血脉精华；在 `灵宠陪伴奖励` 查看当前/历史最佳天数与各档状态。完整错过一个北京时间自然日后当前连续天数归零，但历史最佳达成的奖励资格仍可领取，每档一生领取一次。互动回复会提供奖励页入口，达成的奖励在对应状态行提供领取蓝字；领取凭证与奖励在同一事务内保存，不新增数据库表或列。

想让同族伙伴一起成长，可以先发送 `灵宠合修`。页面只展示本人的在册伙伴，封存宠物须先复原，外出或奖励待领取的宠物须先处理行程。就绪伙伴可按编号直接合修，点击后仍会重新检查条件；QQ 的主要操作为合修与翻页，成长和行程用辅助蓝字，键盘不可用时保留蓝字或可读命令。没有伙伴时先看图鉴或封存库，召唤入口只填入命令，不替你决定次数。

小境界默认必成。大境界失败不降级，但消耗本次全部灵石、已用道具与要求修为的四分之一；每次大境界失败会为该宠物积累 5 个百分点成功率，成功率最高为 100%，成功破境后清零。积累仅用于大境界破境，可与破境丹加成叠加。血脉为凡血、灵血、玄血、真血、仙血，默认进化必成并增强属性。自定义内容调整概率时，进化失败仍消耗本次全部进化成本。

每只灵宠达到凝气、筑基、金丹、元婴、化神或渡劫后，可在 `灵宠境界赏` 逐宠领取该大境界的一次性里程碑奖励；启灵是初始境界，不发此奖励。凝气至渡劫依次奖励 10/20/30/40/50/60 灵石与 1 枚蕴灵丹。凭证按宠物编号和境界 ID 独立保存在 `quest_progress`，与奖励同事务提交；同一宠物同一境界不能重复领取，另一只宠物各自计算。封存伙伴仍可回顾和领奖，`灵宠目标` 汇总已达成与当前可领数量。蕴灵丹内容定义缺失或类型错误时隐藏领取入口并明确拒绝，不写凭证或发放部分奖励；原消息重投不会重复发奖。

每只灵宠亲密达到 25、50、75、100 时，各自解锁一份一次性奖励：分别为 20 灵石与灵粮 1、40 灵石与同心丹 1、60 灵石与回元丹 1、100 灵石与血脉精华 2。`灵宠亲密赏` 按宠物编号和阈值分页展示进度、奖励与状态，封存宠物仍可回顾和领取；可领奖行提供 `灵宠亲密领奖 <宠物编号> <阈值>` 蓝字。领取凭证使用 `quest_progress` 的 `affinity_milestone_reward_<宠物编号>_<阈值>`，并与奖励同事务提交；记录领取时亲密度，重投不重复发奖。奖励物品缺失或类型错误时隐藏入口并拒绝结算。亲密度只从现有互动与喂养进度读取，不新增 schema 或玩家字段。

每只灵宠达到灵血、玄血、真血或仙血后，都可在 `灵宠血脉赏` 分页领取对应一次性奖励，依次为 50/100/150/250 灵石与 1/2/3/4 枚血脉精华。血脉等级单调递增，达到更高等级后，先前未领档位仍可补领。领取凭证按宠物编号与血脉等级写入 `quest_progress`；封存伙伴可回顾和领取，`灵宠目标` 汇总当前可领数。凭证与奖励同事务保存，奖励定义缺失或类型不符时拒绝结算，重投不会重复发奖；不改变血脉进化成本或属性倍率。

修为是可花费的资源，不直接等于战斗力。战斗属性由种族、境界、层数、血脉和亲密决定。精力上限 100，默认每 300 秒恢复 1 点，离线恢复无需后台计时器。切换宠物不会重置玩家冷却。

亲密每提高 10 点，战斗四维各提高 1%。亲密达到 100 后解锁“心契护佑”：每场战斗首次受到控制时自动抵挡一次；之后再次受到控制仍按正常规则结算。状态页会显示解锁情况，永久战报记录战前亲密与是否拥有护佑。

同族合修要求另一只同种族灵宠仍在册且没有未结委托；两只宠物分别按自身境界和种族修炼加成计算修为，不转移或消耗已有修为、装备、技能与血脉分支。合修两只宠物各消耗一次标准修炼精力，但只占用一次玩家共享修炼冷却，并推进一次每日修炼任务。

培育是灵宠之间唯一的产出玩法：两只同种族、亲密都已满 100 的在册灵宠，各消耗 30 精力并支付 800 灵石，即可得到一枚该族灵卵；灵卵用 `灵宠使用 <灵卵>` 孵化，名册有空位时迎接新伙伴。27 个种族各有一枚灵卵，其中 6 枚仍可由秘境掉落。培育不改变参与的两只灵宠，新伙伴从种族初始亲密开始，与孵化所得一致；精力恢复是唯一的节流，不额外设置冷却。列表只展示本人的在册配对，封存宠物须先复原，外出或奖励待领取的宠物须先处理行程；就绪配对挂“培育这一对”蓝字，点击后仍会重新检查条件。

27 种灵宠各有两条专属分支，共 54 条。选择分支消耗 200 修为、300 灵石和 3 个血脉精华，固定成功；每条分支对基础气血、攻击、防御、速度有不同增减，不放大装备固定加成。例如青鸾可选偏攻速的凌风鸾脉，或偏耐久的青木鸾脉。**分支选定后不可更换**；同种族的另一只宠物可选不同分支。选择不会改变种族、主副属性、神通或已学技能，后续普通血脉进化保留分支。

## 物品与任务

```text
灵宠背包
灵宠商店
灵宠商店 2
灵宠购买 灵粮 3
灵宠使用 回元丹 1
灵宠回收 锻灵矿 2
灵宠任务
灵宠领奖 吐纳一周天
灵宠课题
灵宠课题领奖 秘境一胜
```

数量为 1-99 的整数。材料不能直接服用；纯恢复道具在相应属性已满时不会扣除。批量使用会按数量生效，超过上限的恢复量会溢出，请按需使用。

消耗品覆盖精力、修为与亲密三类：灵粮同时提供精力 +20、修为 +10、亲密 +5（售价 20 灵石），回元丹精力 +50（80 灵石），蕴灵丹修为 +100（180 灵石），同心丹亲密 +20（120 灵石）。亲密每 10 点提升战斗四维 1%，满 100 解锁“心契护佑”，因此同心丹是补齐亲密的常用选择；亲密已满时使用会被拒绝，不扣除道具。

灵坊（`灵宠商店`）分页列出在售道具，每条道具行都带“查看详情”蓝字直达 `灵宠商店 <名称>`，按钮只保留翻页与 `灵宠背包`，因此每页五条道具在 QQ 键盘上都可达。乾坤袋（`灵宠背包`）按消耗品、灵卵、装备灵物、灵术秘笈、材料与丹药分组，每行标出该道具的用途，并在该行给出当前真能执行的一步：灵粮挂“喂养”，其他消耗品挂“使用”，灵卵在名册尚有名额时挂“孵化”，装备灵物与灵术秘笈挂只读图鉴入口；材料与破境丹只给用途提示，不挂可执行入口。出战灵宠正在外出派遣、或对应属性已满时，消耗品行不会给出“使用/喂养”，避免点了才被拒绝。购买、使用、喂养与孵化后的回复都会带上 `灵宠背包` 与下一步，方便连续操作。

灵坊回收（`灵宠回收 <物品> <数量>`）把闲置道具按售价的固定比例换回灵石，默认回收价为售价的 40%（`rules.recycle_percent`），按单件向下取整。可回收的是灵坊在售的消耗品、材料、灵术秘笈与破境丹；装备仍走 `灵宠分解`（换成材料、不退灵石），灵卵等没有售价的道具不能回收。由于回收价始终低于售价，买入再回收必然亏损，不会产生套利；回收只改变背包与灵石，不写战报、不推进任务与成就，也不影响伙伴与装备。回收所得不足 1 灵石时会提示一次回收更多。

任务默认包括签到、修炼、喂养、互动、历练、突破、血脉进化、PVE 与排位论剑胜利、委托归来，每日重新计数，每项每天领取一次。签到成功推进“晨光初至”；连续签到里程碑独立于每日任务，按 `灵宠签到奖励` 查看，跨日不重置历史最佳或已达成的领取资格。论剑仅挑战者获胜时推进“论剑扬名”，切磋不计；互动每日限一次，所选灵宠须未外出，亲密已满时仍消耗互动次数并推进连续陪伴与任务，但不再增加亲密；突破和血脉进化均仅成功时计数，失败不计。委托须完成并归来领取后才计入“山海归来”。每日任务名称和奖励可在“灵宠任务”查看，跨日不保留未领取奖励。

除固定十项每日任务外，还有**今日课题**：课题池共 12 项（秘境一胜/三胜/五胜、论剑一试/三试、奇闻一探/双探、委托一程/双程、成就一收/双收、吐纳一回），`灵宠课题` 每天按北京时间日期确定性轮换出其中三项（同一天稳定、四天覆盖全池），玩家**任选其一**完成并领取，当日只能领一项，其余两项显示 `今日已错过`；已选课题显示 `今日已选`。同一指标的多个难度共用同一条当日进度，次数越多奖励越高（灵石 100-420）。可领项挂该行蓝字 `灵宠课题领奖 <课题名>`。进度只统计**当天**的记录（战报、论剑、奇闻发现、委托归来、成就领取与修炼时间），次日 00:00 换新且未领取不累积；`灵宠目标` 会给出今日课题的可领状态。

领取 1、2、4 套装备的完成奖励可分别完成“套装初成”“套装兼收”“套装全收”；全部四套领取后还会解锁派生称号“套装宗师”。进度只统计当前套装目录中已配置奖励的精确 `quest_progress` 领取凭证，不受未领取、未知或自定义无奖励套装记录影响。

每只在册灵宠的每门灵术达到五阶后，都可在 `灵宠灵术赏` 查看进度与领取状态，并领取一次灵石 120 和该术秘笈。列表包含封存伙伴；凭证按宠物编号与技能 ID 独立保存，因此同一只宠物同一灵术不能重复领取，另一只宠物的同一灵术仍有独立奖励。可领奖行提供 `灵宠灵术领奖 <宠物编号> <技能名>` 蓝字；缺失秘笈定义会明确拒绝，不写凭证或发放部分奖励。领取凭证使用 `quest_progress` 的 `skill_mastery_reward_<宠物编号>_<技能 ID>`，与奖励在同一事务提交；原消息重投只返回原回复。累计领取 8 份会获得派生称号“万法宗师”。`灵宠目标` 汇总可领项数量并提供奖励页入口。

当前 74 项成就每页展示五项，逐项列出条件、即时进度、状态与奖励预览，并提供“查看详情”蓝字；已达成且未领取的项目还会在同一行提供唯一“领取奖励”入口。详情页可只读浏览条件、状态和进度，未结契也不会创建玩家档案；尚未领取时展示当前定义的奖励预览，已领取时展示领取时间、领取时进度与数据库中永久保存的实际奖励快照。静态定义之后即使调整，也不会改写已经发放的奖励回顾。

成就达到目标后可领取一次。重复领取会拒绝，原领取消息重投只返回原回复而不重复发奖；发奖与成就领取凭证、奖励快照和回复在同一事务中提交，失败会一并回滚。成就进度即时派生，不新增 schema 或计数列。

### 灵宠扫荡

```text
灵宠扫荡 青岚林
```

已经通关过的单人秘境可以直接扫荡：扣除与战斗相同的精力、进入同一条共享 PVE 冷却，并按该秘境自身的奖励区间即时发放一份掉落，省去重复战斗的等待。通关判定来自永久战报（该玩家在该秘境至少有一场胜利），因此不需要额外计数；败退或平局不算通关。

扫荡不进行战斗，因此不写入战报、不获得技能熟练度、不推进每日任务“斩破迷障”与周常“秘境历练”的获胜场次，也不影响首通与关卡进度——需要这些进度时仍要发送 `灵宠挑战 <秘境名>` 打一场真实战斗。组队秘境不能扫荡，需由队长发起组队挑战；境界门槛、精力与冷却提示与战斗一致。

### 秘境首通

```text
灵宠秘境首通
灵宠秘境首通 2
灵宠秘境首通领奖 青岚林
```

每处秘境（共 20 处，含 11 处组队秘境）首次通关后可以领取一份一次性首通奖励，奖励按境界递增，从青岚林的 150 灵石与 2 锻灵矿到归元峰的 1400 灵石与 6 血脉精华。渡劫境的终章秘境为星陨祭坛（星陨守望）、镜心湖（镜心幻影）、沉星古庭（沉星帝君）与归元峰（归元守御），战斗数值与同境界既有秘境相当。`灵宠秘境首通` 分页列出全部秘境的首通状态（`可领取` / `已领取` / `未通关`）与奖励摘要，可领行挂该行蓝字 `灵宠秘境首通领奖 <秘境名>`；未结契玩家可只读浏览，不建号。

通关判定与扫荡完全同源：来自永久战报（该玩家在该秘境至少有一场胜利），败退或平局不算通关，组队秘境同样按真实胜利判定，每名参战者分别可领。领取标记写入 `quest_progress` 的 `first_clear_<秘境 id>` 行，一次性、不随日期失效，同一秘境不能重复领取；重复消息在缓存期内重投只返回原回复。本功能不改动秘境战斗结算、掉落、精力与冷却——它只在结算路径之外补一份一次性奖励，因此“一次秘境胜利只付秘境自身奖励”的平衡约束不变。`灵宠目标` 也会给出秘境首通的可领数量与入口。

关卡是独立的线性 PVE 进度，共 16 关（启灵到渡劫逐境推进，第 9 关起为渡劫境终章，单人关与组队关交替），不改变普通秘境的可重复挑战规则。关卡有固定前置顺序，每位单人玩家或队员都必须先通关前置关卡，再满足境界、精力和共享 PVE 冷却要求。组队关卡由队长开启，至少两人且所有队员须对当前出战灵宠发送 `灵宠准备`；队长最多出战三只，每位队友只出战一只，整队上限五只。队伍名单和状态在战斗事务内重新校验。

万灵塔是单人逐层试炼，共十六层，难度与首通奖励逐层抬升：一层启灵，二层凝气，三层筑基，四层金丹，五层元婴，六层化神，七层起为渡劫境终章（九至十六层依次为星陨回廊、镜心迷途、沉星古庭、归元试炼、双帝临朝、万法归墟、星陨绝壁、归元绝顶，精力 60-90）。每层有固定前置层，必须按序通关。裸数字按页码处理（与 `灵宠关卡` 一致），查看某层请写层名，例如 `灵宠万灵塔 初入塔门`。

列表显示当前深度（最高已通关层）与每层状态：`可挑战`、`已通关`、`未解锁`；只有 `可挑战` 与 `已通关` 的行挂“前往挑战”蓝字，未解锁行不挂可执行入口。挑战消耗该层精力并进入共享 PVE 冷却，境界、精力、冷却与前置层都在战斗事务内校验。

每层首通奖励只发放一次，并写入该玩家的塔层进度；重复挑战用于练习与熟练度，会照常消耗精力、进入冷却并记录战报，但不再发放首通奖励。失败或平局不推进进度，仍消耗精力与冷却。塔层进度与章节关卡分开统计：`灵宠关卡` 的“章节征服者”只统计十六处章节，塔层另有“三层登临”“六层凌云”“塔顶问道”（第十六层）三条成就，以及“塔门守卫”（三层）与“万灵塔主”（十六层）两项称号。

## PVP 与切磋

论剑是直接挑战镜像的赛季排行榜玩法，不需要对方在线或确认：

```text
灵宠论剑
灵宠匹配
灵宠论剑 10001
灵宠切磋 10001
```

- 不带参数的 `灵宠论剑` 查看当前榜单，或用 `灵宠匹配` 查看合适对手；当前榜单和匹配页面可按 UID 发起挑战。
- 指定对方 UID 后立即战斗，取双方当前出战阵容和各自配装。主动挑战者的每只出战宠物须闲置并各自满足精力要求，同时满足冷却、境界、积分差和次数条件，整场一次事务结算。阵容内灵宠须处于同一大境界，否则不能匹配或开战。
- 默认仅挑战者消耗 20 精力并进入 900 秒论剑冷却；胜方 +20 积分、败方 -20，败方积分不足时以余额为限，平局不改积分。
- 防守是镜像，不改变对方宠物精力（也不触发恢复）、冷却、技能熟练度、队伍准备或外出行程。对方离线、正在派遣或精力不足仍可作为镜像对手；两方积分与胜负平照常记录。
- 每场不发放灵石/修为/道具奖励；计分场次规则见下方赛季说明。
- 结果回复到挑战者当前会话，不主动向对手或其他群推送；不存在邀请、应战或拒战指令。

`灵宠切磋 10001` 同样立即以双方当前阵容与镜像战斗，不消耗双方资源、不计积分、不发奖励或技能熟练度，也没有论剑境界/分差门槛。主动切磋的全部出战宠物必须闲置，防守镜像不受占用影响。

使用 `灵宠战报` 查看自己参与的论剑、切磋、秘境和关卡记录，每页五场。选择战报后，技能/装备/主属性摘要和逐条战斗记录每页八行：

```text
灵宠战报
灵宠战报 2
灵宠战报 查看 17
灵宠战报 详情 17 2
```

新战报会固定保存战斗发生时的秘境/关卡/赛季名称、参战 UID、宠物、属性、已携带技能及等级熟练度、装备强化、胜负与回合日志；之后更换伙伴、学习技能、强化装备或调整静态内容不会改写历史。升级前的历史战报可能保留当时的旧称谓，不代表当前仍支持按旧称谓交互。只有该场参与者可读取详情；组队成员退队后仍可查本人参与过的记录。战报查询回复当前会话，不主动私聊其他参与者。

`灵宠排行` 是独立的修为榜，每人取境界最高的一只宠物入榜，不因收藏大量宠物占满排行。

赛季按北京时间自然月划分，`YYYY-MM` 为赛季号，每月一日 00:00 换季。每季独立从 1000 分开始，旧季积分、结果与领奖记录保留；只查询不会进入榜单。跨月不重置玩家论剑冷却，旧挑战消息重投只返回当时结果，不记入新季或重复扣费。

默认需达到凝气，双方同一大境界且积分差不超过 200；每人每日最多主动挑战 5 场，同对每日最多 1 场、每季最多 3 场，反向挑战仍视为同对。平局照常消耗挑战者精力、冷却和场次，但不增加领奖所需的有效胜负局或不同对手数。镜像防守不消耗每日主动次数，也不增加领奖资格。资格不足会明确拒绝，不自动改成切磋。

赛季奖励需至少 10 场主动挑战有效胜负、4 名不同有效对手，按**赛季最终积分**选一个最高符合档位，不累加各档奖励。默认青云档 0 分：300 灵石、3 锻灵矿；凌霄档 1050 分：600 灵石、6 锻灵矿、2 血脉精华；天阙档 1150 分：1000 灵石、10 锻灵矿、4 血脉精华；星海档 1250 分：1400 灵石、13 锻灵矿、5 血脉精华；太虚档 1350 分：1900 灵石、16 锻灵矿、6 血脉精华；归元档 1450 分：2500 灵石、20 锻灵矿、8 血脉精华。只发账户灵石和物品，不给宠物修为，也不因收藏宠物增加奖励。

赛季首次开放时固定规则与奖励，管理员修改静态配置只影响之后新开的赛季。结束后主动领奖，不自动发放，也不因离线跨月丢失资格；重复点击、并发和旧消息重投不能重复领奖。服务器时钟回退时竞技操作会拒绝，等待恢复后重试。

这些规则限制重复对局收益，不做不同 ID 绑定、设备追踪或身份推测。实际奖励和限制以服务器当前赛季页面为准。

除档位奖励外，每个赛季还有十项**赛季任务**：五项轻量目标（论剑历练 10 场、论剑争锋 5 胜、山海征战 5 胜、奇闻寻访 3 条、成就累积 3 项）与五项进阶目标（论剑百战 30 场、论剑称雄 15 胜、山海远征 15 胜、奇闻遍访 8 条、成就盈册 8 项），进阶奖励约为轻量版两倍（灵石 650-900）。同一指标的多个目标共用同一条本赛季进度，玩家可以只做轻量目标，也可以继续冲进阶目标。`灵宠赛季任务` 逐项给出奖励摘要、说明与状态（`进行中（n/target）`/`可领取`/`已领取`），并显示赛季号与剩余天数；可领项挂该行蓝字 `灵宠赛季任务领奖 <任务名>`。进度只统计**当前赛季窗口内**的记录：论剑场次与胜场按 `pvp_results.season_id`，秘境获胜按战报时间，奇闻与成就按记录时间戳。领取标记按赛季起始时间保存，换季后全部重新可领，未领取不累积；`灵宠目标` 也会给出可领项数与已领取进度。

赛季内爬档本身也有回报：`灵宠段位奖励` 列出六档段位的最低积分、一次性达成奖励与状态（`可领取`/`已领取`/`还差 n 分`），当前赛季积分达到该档即可领取，可领项挂该行蓝字 `灵宠段位领奖 <段位名>`。奖励按档位递增（青云 80 灵石 → 归元 700 灵石、10 锻灵矿、4 血脉精华），每档每季只能领取一次，换季后全部重新可领、未领取不累积；它与赛季结束按最终积分结算的档位奖励互不影响，也不消耗每日场次或领奖资格。领取标记写入 `quest_progress` 的 `arena_tier_<赛季号>_<档位 id>` 行。`灵宠目标` 也会给出可领档数与当前积分。

## 组队 PVE

1. 队长发送 `灵宠组队`，通过 `我的信息` 告知队友自己的 UID。
2. 候选成员发送 `灵宠入队 队长UID` 提交申请，队长再发送 `灵宠队伍同意 候选成员UID`。申请不会直接加入队伍。
3. 也可由队长发送 `灵宠邀请 候选成员UID`，受邀者再发送 `灵宠队伍同意 队长UID`。队长不能代替受邀者确认，候选人也不能批准自己的入队申请。
4. 入队后每人发送 `灵宠准备`，同意下一次组队战斗消耗当前灵宠的精力和 PVE 冷却。
5. 队长发送 `灵宠组队挑战 上古灵殿`，至少两人、全员准备且满足准入与资源要求才能开始。
6. 胜利后每位成员获得一份独立奖励；战后全员取消准备，下次须重新准备。

默认最多三人，同一玩家不能同时加入多个队伍。所有队伍交互均使用对方 UID，不接受内部队伍编号。例如队长 UID 为 `10000`、候选成员为 `10001`，候选人发送 `灵宠入队 10000`，队长发送 `灵宠队伍同意 10001`。申请和邀请默认 600 秒有效，不预留名额，同意时重新检查余位及候选人是否已有队伍。两人之间已有请求时，不会覆盖、自动同意或延长有效期；须按原方向处理或由发起人撤回。每队和每名候选人默认各最多 10 条有效请求。

| 指令 | 作用 |
| --- | --- |
| 灵宠队务 / 灵宠队务 分页 2 | 查看与自己有关的待处理队务，每页四条；队长同时查看本队请求 |
| 灵宠队务 对方UID | 查看请求详情、有效期和自己可执行的动作 |
| 灵宠队伍同意 对方UID | 处理方同意申请或邀请；发起人不能代为同意 |
| 灵宠队伍拒绝 对方UID | 仅处理方可以拒绝 |
| 灵宠队伍撤回 对方UID | 仅发起人可以撤回 |
| 灵宠队伍 / 灵宠队伍 成员UID | 查看本队成员、准备状态及成员管理入口 |
| 灵宠取消准备 | 撤回自己的出征授权 |
| 灵宠退队 | 普通成员离队；队长须先转让或显式解散 |
| 灵宠踢人 成员UID | 队长移出本队其他成员，不能踢自己或操作其他队伍 |

队务建议用 `灵宠队务 分页 2` 翻页，`分页` 与页码之间留空格。裸数字小于 `10000` 时作为页码处理，`10000` 起作为 UID 查询详情；也可写 `灵宠队务 UID 10001`。翻页入口使用明确的 `分页 N`，不会把对方 UID 当页码。

小队页面（`灵宠队伍`）里每位其他成员都在自己的行上提供“查看名帖”蓝字，直达 `灵宠队伍 成员UID`；容量行提供“组队指南”蓝字，直达 `灵宠帮助 组队与派遣`。队员名帖的身份行同样提供“组队指南”蓝字。页面按钮只保留页面级动作，成员再多也不会因为四条上限而看不到后面成员的名帖。建队、入队、邀请、同意、拒绝、撤回、准备与取消准备的回复都会附上“组队指南”入口，方便随时回看这一章。

小队页面只在**至少两人且全员已准备**时给出 `灵宠组队挑战`，只在出战宠齐全且都未外出派遣时给出 `灵宠准备`（已准备时改为 `灵宠取消准备`），因此页面上的入口都是当前真能执行的；业务层仍会独立复核准备、境界、精力与冷却。

成功入队会取消该玩家在所有队伍的其他申请和邀请；自己建队同样清除自己的候选请求。转让队长会取消本队全部待处理队务，旧队长的邀请不继续生效。普通队务、建队和管理操作不消耗精力、灵石或道具，也不发放奖励。

加入、退出、踢人或队长转让后，**全队准备状态失效**，须重新确认。切宠、修炼、历练、进化、突破、服用道具、变更装备/技能、单人秘境或主动论剑，只取消行动者自己的准备状态；镜像防守及切磋不取消准备，组队战斗取消全体参战成员准备。组队战斗与队伍变动按事务先后处理，不会在同一场结算中途更换参战名单或只扣部分成员资源。

指定编号修炼、突破、进化、喂养或互动时，准备失效按实际组队参战宠判断：队长阵容内的三只均生效，队友只有首宠生效；养成未参战的备用宠不会取消准备。突破或进化失败但已结算成本时同样取消对应参战宠的准备；资源不足等拒绝会整笔回滚并保留准备。养成消息在约七日通用缓存内重投不会撤销后来重新确认的准备；缓存过期后按新操作检查并执行，养成指令没有战斗的永久重放凭证。

队务查询权限限定为请求当事人和当前队长，成员详情只可查询本队。**回复仍发送到当前会话，群内查询的结果会被群成员看到，不会自动转为私聊。**队伍是同一存档内的全服队伍，不限制在单个群；邀请不会主动向其他群或私聊推送，受邀者使用 `灵宠队务` 查询。两个适配器仍按后台平台 ID 区分人物，不绑定不同 ID；UID 固定，不受伙伴资料变化影响。

一人资源不足时整个挑战不扣费，不会先扣队友资源。无需同时在线，但必须提前明确准备。上古灵殿从启灵开放，幽冥深渊从筑基开放；提高层数、血脉或凑齐三人更容易战胜敌人。

类别和元素是不同维度。技能或装备可以同时要求境界、类别与元素；全部条件都满足才可使用。例如玄狐不能学习水箭术，三灵鹿可以学习风刃术、赤焰术和青木回春；风火燎原要求同时具备风、火并达到凝气，不是任意满足其中一个。

冰是水的分支：冰宠可满足水系技能、装备的元素条件，但只有水属性的宠物不能学习冰系专属术法。类别与境界门槛仍须满足。风、雷、毒为独立特殊元素，不因名称或现实联想自动归入某个五行。

## 属性克制与天赋

- 普通攻击使用攻击者的主属性；伤害技能使用技能自身属性，通用无属性技能按中性处理。
- 受击方只以主属性参与克制。副属性用于可学习技能、可装备物品及对应天赋条件，不作为第二层防御倍率。
- 五行：金克木、木克土、土克水、水克火、火克金。特殊关系：风克土、雷克水、毒克木。
- 优势倍率 1.25，受克倍率 0.8，无关系为 1.0。冰继承水的关系，因此冰克火，同时受土、雷克制；不重复叠乘祖先关系。
- 例如三灵鹿主木、副风火，受金系攻击时按木被克制，不会用副火抵消。毕方即使元素列表把风写在前面，普攻仍用明确记录的主属性火。

每种宠物都有天赋神通，无需秘笈，不占携带技能栏。当前包括增伤、首击、吸血、反击、开场护盾、行动回血、残血追击、闪避、毒伤、穿透防御十类效果，具体数值见该宠物图鉴。

增伤倍率在扣除防御之前计算。护盾每场仅在开始时生成；反击不会触发反击链。毒、吸血和受击反击都要求直接攻击实际造成气血损失，护盾完全吸收时不触发；吸血不会复活已经倒下的灵宠。中毒在目标行动前扣血，持续三次行动，再次命中刷新而不叠层，毒伤绕过护盾；战斗结束清除所有临时效果。最多 40 回合，不会无限交战。

## 装备与灵术

```text
灵宠装备图鉴
灵宠套装
灵宠套装 青岚风铃
灵宠购买 青岚翎 1
灵宠装备 青岚翎
灵宠装备
灵宠强化 灵器
灵宠强化 灵器 5
灵宠卸装 灵器
灵宠技能图鉴
灵宠购买 风刃术诀 1
灵宠学习 风刃术
灵宠技能
灵宠卸技 风刃术
灵宠携带 风刃术
```

每只宠物有灵器、护甲、饰品三个位置。穿戴从共享背包取走一件，替换或卸装返回背包；一件不能同时给两只宠物穿戴。装备提供固定属性加成，并真正参与 PVE、PVP 和切磋。

四套装备组合提供长期配装目标：青岚风铃（青岚翎、灵心铃）、山岳镇魂（玄岩甲、山心石）、幽鳞蚀锋（幽鳞衣、蚀灵刺）和木灵缚甲（灵丝甲、长生根）。`灵宠套装` 查看目录，名称查询可查看套件组成与加成。必须由同一只灵宠同时装备套件全部部件才会激活；装备页显示 `未激活` 或 `已激活` 与当前套装属性，战报会记录战斗开始时实际生效的套装。木灵缚甲可由木属性植族伙伴穿戴，灵丝甲也适用于虫族。

首次由当前出战灵宠配齐任一套装后，可在 `灵宠套装` 对应行领取一次性完成奖励；目录和套装详情会列出奖励及领取状态，达成行提供 `灵宠套装领奖 <套装名>` 蓝字。奖励为青岚风铃 180 灵石与灵粮、山岳镇魂 240 灵石与锻灵矿、幽鳞蚀锋和木灵缚甲各 300 灵石与血脉精华。领取后即使卸装或换宠，已领取状态也会保留；必须重新由同一只当前出战灵宠穿齐全套后才能领取尚未领取的套装奖励。`灵宠目标` 会汇总当前可领套装奖励数。

强化针对当前宠物已穿戴装备，可填槽位或装备名称，每次升一级，+0 至 +10，固定成功。消耗灵石和锻造材料，当前装备面板列出下一阶成本。每级仅让装备自身的加成增加原始值的 20%，+10 为三倍，不把整只宠物的属性放大。卸装、换宠或重新穿戴保留强化，背包按强化等级分开显示，同名优先穿戴背包中强化最高的一件。

也可以直接写目标等级一次强化到位，例如 `灵宠强化 灵器 5`：系统按阶梯累加从当前等级到目标等级的灵石与材料，在同一事务内一次结算，成功后装备直接变为目标等级。整条命令是原子的——灵石或材料不足时会被整条拒绝，并给出需要的总消耗与当前灵石，等级、灵石与材料都不会变化；目标等级须为 1-10 的整数且高于当前等级，超过 +10 会被拒绝。逐级定价、倍率与回收规则完全不变。

技能学会后永久记在该宠物上，消耗一本对应秘笈；同一技能不会重复学习或消耗。默认最多携带两个，学会更多时保存为未携带状态，卸技只卸下，不遗忘，不返还秘笈。

技能从 1 级开始，最高 5 级。在单人/组队 PVE 和积分论剑中，每次真正施放获得 5 点熟练度，胜败均计；没有行动、未携带的技能、天赋、切磋都不奖励。伤害技能被闪避仍算已经施放；满血时治疗技能回退普攻，不计该技能熟练度。升级依次消耗 20、50、100、180 点熟练度，超额结转，满级后停止积累。等级威力倍率依次为 1、1.12、1.25、1.4、1.6，对伤害与恢复都生效；治疗不超过最大气血。

战斗按已携带技能的固定顺序轮流施展。普通伤害技能攻击一个敌人；凝气通用灵术“灵潮荡阵”以 0.65 倍基础系数攻击所有存活敌人，每个目标分别计算闪避、属性克制、护盾和受击天赋，整次施法只计一次熟练度。群攻不受嘲阵改变目标范围。恢复技能按最大气血比例回复自己，满气血时改用普通攻击。没有技能时正常普攻；本版没有法力或技能秒数冷却。

技能等级、熟练度属于每只宠物自己的存档，卸技、重新携带、切宠不丢失，也不会自动共享给同种族的其他宠物。战后成长与精力、奖励、消息去重一起提交，同一战报重投不会再次增加熟练度。

装备图鉴、套装图鉴、技能图鉴、商店均支持页码或名称查询，每页 5 项，不再一次刷出全部内容。例如 `灵宠套装 1`、`灵宠技能图鉴 2`、`灵宠技能图鉴 霜封术`、`灵宠商店 锻灵矿`。商店列表的每条道具行都带“查看详情”蓝字，可直接进入该道具详情并购买。

## 控制与驱散

以下灵术均可从商店购买对应秘笈，再按元素和境界门槛学习：

| 灵术 | 效果 |
| --- | --- |
| 霜封术 | 冰系伤害，附加跳过一次行动的控制 |
| 蚀力毒咒 | 毒系伤害，暂时降低目标攻击 |
| 岩灵护障 | 为自身生成有行动次数期限的护盾 |
| 清心灵息 | 恢复自身，并净化己方负面状态最多的单位 |
| 破障术 | 驱散敌方天赋护盾、临时护盾与攻击增益 |
| 战意灵歌 | 为己方攻击最高且仍可受益的单位增加攻击 |
| 镇岳护阵 | 灵息伤害并嘲阵两次自身行动；敌方优先攻击护阵目标，可被破障术驱散 |
| 灵潮荡阵 | 无属性灵息攻击全体存活敌人；目标分别判定闪避、护盾和受击天赋 |

受控单位跳过一次行动，随后至少获得一次完整行动的免控，不能被快手或多名对手连续锁住。跳过行动也会推进持续效果的剩余次数，但不会推进技能轮换或获得熟练度。被控者不能自行施法净化，需要队友解除。

同类弱化、增益、临时护盾保留较强效果并刷新持续次数，不相加；弱化与增益可共存，分别乘到攻击。普通攻击和反击使用当前有效攻击。临时护盾先于天赋护盾吸收伤害，护盾仍可被驱散，毒伤依旧绕过护盾。

嘲阵持续时间按护阵者自己的后续行动计算，不影响其队友的行动次数；嘲阵有效时，对手的攻击与技能目标优先指向护阵者。多个目标同时护阵时再从中随机选择；护阵可被破障术驱散。


满血治疗若能执行有效净化，仍会施放并计熟练度；没有可恢复气血、可净化状态或可施加效果时，回退主属性普攻，不算该技能施放。控制、弱化、驱散可被闪避，伤害附加效果仅命中时生效；所有状态战后清空。

## 打造与分解

```text
灵宠工坊
灵宠工坊 青岚翎 +3
灵宠打造 青岚翎 2
灵宠分解 青岚翎 1
灵宠分解 青岚翎 +3 1
灵宠强化继承 青岚翎 灵心铃
```

工坊覆盖全部 14 件装备，显示精确打造成本和指定强化等级的回收量。打造消耗灵石和材料，获得 +0 装备，数量为 1-99。装备适用限制在穿戴时检查，不能用打造绕过元素、类别和境界门槛。

强化继承把一件背包装备的强化等级交给同部位的另一件未强化装备：源装备取背包内最高强化等级，目标必须是同部位、未强化且仍在背包的装备；成功后源装备回到 +0、目标装备变为该等级，成本按源等级计算（默认每级 80 灵石与 1 锻灵矿）。穿戴中的装备须先卸装，双方不能是同一件，部位不同、源未强化、目标已有强化或资源不足都会被拒绝。继承后的装备可正常穿戴、继续强化或分解。

分解只消耗背包中的指定装备，不会自动拆掉穿戴中的装备。不填强化等级时只分解 +0，强化件必须明确写 `+N`。回收基础材料加累计强化材料的至多 50%，按每件、每种材料向下取整；不退还任何打造或强化灵石。高等级材料不会按多件合并后多返，反复打造、强化、分解不能复制材料。
