# 玩法说明

命令可带 `/`，也可不带。参数前留空格。QQ 群内一般先 @机器人，按钮由点击者自己的身份执行。两端 ID 不同就是不同玩家，不做绑定。

## 结契与灵宠

| 指令 | 作用 |
| --- | --- |
| 灵宠领养 青鸾 | 首次结契，可选青鸾、玄狐、白泽、蛟龙；不填名称则随机初始种族 |
| 灵宠召唤 1 | 每次 100 灵石，支持 1-10 次，概率见图鉴 |
| 灵宠列表 1 | 每页 5 只，显示实例编号；星号为当前出战宠物 |
| 灵宠切换 2 | 用列表中的编号切换，同名多宠必须用编号 |
| 我的灵宠 | 查看境界层数、血脉、属性、资源和下一阶段要求 |
| 灵宠改名 小青 | 1-12 个汉字、字母或数字 |
| 灵宠图鉴 1 / 灵宠图鉴 毕方 | 分页浏览，或查看指定种族的主副属性、天赋和获取途径 |
| 灵宠使用 灵卵名称 1 | 消耗秘境掉落的灵卵，孵化对应种族的新宠 |
| 我的道号 | 查看自己的唯一道号 |
| 灵宠道号 听雨散人 | 修改道号，2-12 个汉字、字母或数字，全服不可重复 |

结契时从多段词库的 20,971,520 个不同候选中随机生成六字或八字道号，冲突时自动另取；不需要展开两千万个名字到内存。字母大小写不产生两个相同道号。原始 ID 只用于后台区分人物，不显示给玩家，不作为交互参数。改道号不影响队伍、赛季或存档。

初始选择固定为青鸾、玄狐、白泽、蛟龙，不会随着图鉴扩充而增加。目前共 27 种灵宠，其他种族通过召唤或秘境灵卵获得。灵卵孵化前会检查容量，不足时不消耗；孵化不会自动切换出战宠物。每只灵宠独立成长，共用玩家的灵石、背包、任务与行动冷却，默认最多 50 只。

青鸾偏修炼与风系增伤，玄狐偏首击突袭，白泽带开场护盾，蛟龙擅长破甲。同元素也有不同定位，例如火系玄狐抢攻、毕方强化火系威力、赤焰虎追击残血、熔岩甲受击反震，不是仅替换名称的同一套数值。

## 成长与进化

大境界：启灵 → 凝气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫，每个境界一至十层。

| 指令 | 规则 |
| --- | --- |
| 灵宠签到 | 北京时间每日 00:00 刷新，默认 200 灵石、3 份灵粮 |
| 灵宠喂养 | 使用 1 份灵粮，精力 +20、修为 +10、亲密 +5 |
| 灵宠修炼 | 默认消耗 15 精力，冷却 300 秒，按种族与大境界获得修为 |
| 灵宠突破 | 一至九层为小境界突破；十层为大境界破境，成功后进入下一境界一层 |
| 灵宠突破 破境丹 | 大境界破境时额外消耗 1 丹，增加 10 个百分点成功率 |
| 灵宠进化 | 消耗面板显示的修为、灵石、血脉精华，独立提升血脉等级 |
| 灵宠血脉 / 灵宠血脉 青鸾 | 查看当前或指定种族的两个血脉分支、倍率与成本 |
| 灵宠分支 凌风鸾脉 | 达到灵血后选定当前种族的分支，每只宠物只能选一次 |

小境界默认必成。大境界失败不降级，但消耗本次全部灵石、已用道具与要求修为的四分之一。血脉为凡血、灵血、玄血、真血、仙血，默认进化必成并增强属性。自定义内容调整概率时，进化失败仍消耗本次全部进化成本。

修为是可花费的资源，不直接等于战斗力。战斗属性由种族、境界、层数、血脉和亲密决定。精力上限 100，默认每 300 秒恢复 1 点，离线恢复无需后台计时器。切换宠物不会重置玩家冷却。

27 种灵宠各有两条专属分支，共 54 条。选择分支消耗 200 修为、300 灵石和 3 个血脉精华，固定成功；每条分支对基础气血、攻击、防御、速度有不同增减，不放大装备固定加成。例如青鸾可选偏攻速的凌风鸾脉，或偏耐久的青木鸾脉。**分支选定后不可更换**；同种族的另一只宠物可选不同分支。选择不会改变种族、主副属性、神通或已学技能，后续普通血脉进化保留分支。

## 物品与任务

```text
灵宠背包
灵宠商店
灵宠商店 2
灵宠购买 灵粮 3
灵宠使用 回元丹 1
灵宠任务
灵宠领奖 吐纳一周天
```

数量为 1-99 的整数。材料不能直接服用；纯恢复道具在相应属性已满时不会扣除。批量使用会按数量生效，超过上限的恢复量会溢出，请按需使用。

任务默认包括修炼、喂养、历练和 PVE 胜利，每日重新计数，每项每天领取一次。名称和奖励可在“灵宠任务”查看，跨日不保留未领取奖励。

## 离线委托

| 指令 | 作用 |
| --- | --- |
| 灵宠委托 / 灵宠委托 采灵药 | 查看任务目录或具体要求与奖励区间 |
| 灵宠派遣 采灵药 | 派遣当前灵宠，出发时扣除精力 |
| 灵宠行程 / 灵宠行程 1 | 查看最近或指定的本人行程，显示剩余时间或结算状态 |
| 灵宠归来 1 | 指定行程完成后领取一次奖励；不填编号只查询，不领奖 |
| 灵宠召回 1 | 提前结束指定行程，无奖励且不退精力；不填编号只查询 |

这里的 `1` 是回复中的**行程编号**，不是玩家 ID。旧行程按钮不能领取或召回新行程；他人的行程无法查询或操作。回复仍发送到当前会话，群内查询结果对群成员可见，不自动转为私聊。

| 委托 | 门槛 | 精力 | 主要产出 |
| --- | --- | --- | --- |
| 采灵药 | 启灵 | 25 | 灵粮 1-2、修为 15-25、灵石 10-20 |
| 寻锻矿 | 凝气 | 30 | 锻灵矿 1-2、修为 20-35、灵石 15-30 |
| 探血髓 | 筑基 | 40 | 血脉精华 1、修为 30-50、灵石 20-40 |

默认每项行程 3600 秒，每名玩家同时只能派遣一只宠物，不因收藏更多宠物增加并行委托数。委托固定成功，不进行离线战斗；到期无需机器人一直在线，也不自动发奖。完成后仍占用宠物，直至手动归来领取，且不能再提前召回。行程不会因跨日过期。

出发时固定本次奖励和完成时间，之后调整配置或奖励区间不会改变在途收益。修为始终给出发的那只宠物，切换出战宠物不会转移修为；灵石和道具进入本人账户及背包。失败结算整体回滚，不会丢失未领取奖励。

外出及待领奖宠物不能修炼、历练、突破、进化、选分支、使用养成消耗品、变更装备/技能或主动参加战斗，主动切磋也不例外；作为他人的镜像对手不受影响，不改变外出宠物状态。派遣会取消本人的组队准备，外出宠不能重新准备；其他队友不被代为操作。可以切换闲置宠物继续养成、参战和准备，查询、改名、召唤孵蛋、购买道具、打造分解与队伍管理仍可用。自然精力恢复保留。

只有灵石/道具的签到和任务奖励不受宠物占用影响；会发修为的每日任务须切换到闲置宠物后领取，不能借领奖给外出宠养成。召回也受服务器时间校验，时钟回退时不会提前领奖或重开已结算行程。

## 单人 PVE

```text
灵宠历练
灵宠秘境
灵宠秘境 九霄劫海
灵宠挑战 青岚林
```

历练是随机奇遇，消耗 25 精力，默认冷却 900 秒。秘境是实际回合战斗，准入境界不代表一定获胜。秘境目录每页 5 处，可用页码翻页，或按名称查看敌人的主属性、四维和奖励区间。

| 境界 | 单人秘境 | 组队秘境 |
| --- | --- | --- |
| 启灵 | 青岚林 | 上古灵殿 |
| 凝气 | 月影谷、寒晶洞、腐毒沼 | 潮生宫 |
| 筑基 | 雷泽 | 幽冥深渊 |
| 金丹 | 焚天峰 | 玄玉天阙 |
| 元婴 | 万载霜渊 | 万木归墟 |
| 化神 | 太虚剑境 | 冥帝幽庭 |

战斗最多 40 回合，所有参战单位从满气血开始，气血仅属于本场，不需要持久化治疗。胜利获得修为、灵石和秘境对应的材料、灵卵；败退或平局没有胜利奖励，但实际施放的技能仍获得熟练度。无论胜败均消耗精力并进入 PVE 冷却，单人和组队秘境默认共享 600 秒冷却。

## PVP 与切磋

论剑是直接挑战镜像的赛季排行榜玩法，不需要对方在线或确认：

```text
灵宠论剑
灵宠匹配
灵宠论剑 对方道号
灵宠切磋 对方道号
```

- 不带参数的 `灵宠论剑` 查看当前榜单；可点击道号挑战按钮，或用 `灵宠匹配` 查看合适对手。
- 指定道号后立即战斗，取双方当前出战宠物和配装。主动挑战者须闲置、满足精力、冷却、境界、积分差和次数条件，整场一次事务结算。
- 默认仅挑战者消耗 20 精力并进入 900 秒论剑冷却；胜方 +20 积分、败方 -20，败方积分不足时以余额为限，平局不改积分。
- 防守是镜像，不改变对方宠物精力（也不触发恢复）、冷却、技能熟练度、队伍准备或外出行程。对方离线、正在派遣或精力不足仍可作为镜像对手；两方积分与胜负平照常记录。
- 每场不发放灵石/修为/道具奖励；计分场次规则见下方赛季说明。
- 结果回复到挑战者当前会话，不主动向对手或其他群推送；不存在邀请、应战或拒战指令。

`灵宠切磋 对方道号` 同样立即与镜像战斗，不消耗双方资源、不计积分、不发奖励或技能熟练度，也没有论剑境界/分差门槛。主动切磋的宠物必须闲置，防守镜像不受占用影响。

`灵宠排行` 是独立的修为榜，每人取境界最高的一只宠物入榜，不因收藏大量宠物占满排行。

## 论剑赛季

| 指令 | 作用 |
| --- | --- |
| 灵宠赛季 / 灵宠赛季 2028-01 | 本季或历史赛季时间、个人积分、战绩和领奖资格 |
| 灵宠匹配 / 灵宠匹配 2 | 分页查看符合条件的候选道号及论剑入口；不代表对方在线 |
| 灵宠论剑榜 / 灵宠论剑榜 2028-01 分页 2 | 当前或历史赛季榜单，每页五人；当前榜可直接挑战 |
| 灵宠赛季奖励 | 查看本人已结束的参赛赛季，尚无历史时显示当季奖励档位 |
| 灵宠赛季奖励 规则 / 灵宠赛季奖励 规则 2028-01 | 查看当前或指定赛季的奖励档位 |
| 灵宠赛季领奖 2028-01 | 为指定已结束赛季领取一次奖励 |

赛季按北京时间自然月划分，`YYYY-MM` 为赛季号，每月一日 00:00 换季。每季独立从 1000 分开始，旧季积分、结果与领奖记录保留；只查询不会进入榜单。跨月不重置玩家论剑冷却，旧挑战消息重投只返回当时结果，不记入新季或重复扣费。

默认需达到凝气，双方同一大境界且积分差不超过 200；每人每日最多主动挑战 5 场，同对每日最多 1 场、每季最多 3 场，反向挑战仍视为同对。平局照常消耗挑战者精力、冷却和场次，但不增加领奖所需的有效胜负局或不同对手数。镜像防守不消耗每日主动次数，也不增加领奖资格。资格不足会明确拒绝，不自动改成切磋。

赛季奖励需至少 10 场主动挑战有效胜负、4 名不同有效对手，按**赛季最终积分**选一个最高符合档位，不累加各档奖励。默认青云档 0 分：300 灵石、3 锻灵矿；凌霄档 1050 分：600 灵石、6 锻灵矿、2 血脉精华；天阙档 1150 分：1000 灵石、10 锻灵矿、4 血脉精华。只发账户灵石和物品，不给宠物修为，也不因收藏宠物增加奖励。

赛季首次开放时固定规则与奖励，管理员修改静态配置只影响之后新开的赛季。结束后主动领奖，不自动发放，也不因离线跨月丢失资格；重复点击、并发和旧消息重投不能重复领奖。服务器时钟回退时竞技操作会拒绝，等待恢复后重试。

这些规则限制重复对局收益，不做不同 ID 绑定、设备追踪或身份推测，也不声称能杜绝多账号串谋。初始分差、限额和奖励属于开发期数值，并非已经完成全部竞技平衡。

## 组队 PVE

1. 队长发送 `灵宠组队`，以自己的道号带队。
2. 候选成员发送 `灵宠入队 队长道号` 提交申请，队长再发送 `灵宠队伍同意 候选成员道号`。申请不会直接加入队伍。
3. 也可由队长发送 `灵宠邀请 候选成员道号`，受邀者再发送 `灵宠队伍同意 队长道号`。队长不能代替受邀者确认，候选人也不能批准自己的入队申请。
4. 入队后每人发送 `灵宠准备`，同意下一次组队战斗消耗当前灵宠的精力和 PVE 冷却。
5. 队长发送 `灵宠组队挑战 上古灵殿`，至少两人、全员准备且满足准入与资源要求才能开始。
6. 胜利后每位成员获得一份独立奖励；战后全员取消准备，下次须重新准备。

默认最多三人，同一玩家不能同时加入多个队伍。所有队伍交互均使用道号，不接受内部队伍编号。申请和邀请默认 600 秒有效，不预留名额，同意时重新检查余位及候选人是否已有队伍。两人之间已有请求时，不会覆盖、自动同意或延长有效期；须按原方向处理或由发起人撤回。每队和每名候选人默认各最多 10 条有效请求。

| 指令 | 作用 |
| --- | --- |
| 灵宠队务 / 灵宠队务 分页 2 | 查看与自己有关的待处理队务，每页四条；队长同时查看本队请求 |
| 灵宠队务 对方道号 | 查看请求详情、有效期和自己可执行的动作 |
| 灵宠队伍同意 对方道号 | 处理方同意申请或邀请；发起人不能代为同意 |
| 灵宠队伍拒绝 对方道号 | 仅处理方可以拒绝 |
| 灵宠队伍撤回 对方道号 | 仅发起人可以撤回 |
| 灵宠队伍 / 灵宠队伍 成员道号 | 查看本队成员、准备状态及成员管理入口 |
| 灵宠取消准备 | 撤回自己的出征授权 |
| 灵宠退队 | 普通成员离队；队长须先转让或显式解散 |
| 灵宠踢人 成员道号 | 队长移出本队其他成员，不能踢自己或操作其他队伍 |
| 灵宠转让 成员道号 | 队长把带队权交给本队其他成员，旧队长留为队员 |
| 灵宠解散 | 仅队长可解散，清除本队成员和全部待处理请求 |

`分页 2` 中间的空格用于区分合法道号；例如道号 `12`、`第2页`、`分页` 均可正常查看详情。裸数字也可作为页码简写，但存在同名玩家时优先按道号解释，翻页按钮始终使用无歧义的 `分页 N`。

成功入队会取消该玩家在所有队伍的其他申请和邀请；自己建队同样清除自己的候选请求。转让队长会取消本队全部待处理队务，旧队长的邀请不继续生效。普通队务、建队和管理操作不消耗精力、灵石或道具，也不发放奖励。

加入、退出、踢人或队长转让后，**全队准备状态失效**，须重新确认。切宠、修炼、历练、进化、突破、服用道具、变更装备/技能、单人秘境或主动论剑，只取消行动者自己的准备状态；镜像防守及切磋不取消准备，组队战斗取消全体参战成员准备。组队战斗与队伍变动按事务先后处理，不会在同一场结算中途更换参战名单或只扣部分成员资源。

队务查询权限限定为请求当事人和当前队长，成员详情只可查询本队。**回复仍发送到当前会话，群内查询的结果会被群成员看到，不会自动转为私聊。**队伍是同一存档内的全服队伍，不限制在单个群；邀请不会主动向其他群或私聊推送，受邀者使用 `灵宠队务` 查询。两个适配器仍按原始 ID 区分人物，不绑定不同 ID。改道号后请求关系保留，后续操作使用新道号。

一人资源不足时整个挑战不扣费，不会先扣队友资源。无需同时在线，但必须提前明确准备。上古灵殿从启灵开放，幽冥深渊从筑基开放；提高层数、血脉或凑齐三人更容易战胜敌人。

类别和元素是不同维度。技能或装备可以同时要求境界、类别与元素；全部条件都满足才可使用。例如玄狐不能学习水箭术，三灵鹿可以学习风刃术、赤焰术和青木回春；风火燎原要求同时具备风、火并达到凝气，不是任意满足其中一个。

龙鳞甲仅限龙族；雷霆吐息要求龙族且具备雷系。学习和携带都会检查，不能先在别的宠物上学习再通过切宠共享技能。

冰是水的分支：冰宠可满足水系技能、装备的元素条件，但只有水属性的宠物不能学习冰系专属术法。类别与境界门槛仍须满足。风、雷、毒为独立特殊元素，不因名称或现实联想自动归入某个五行。

## 属性克制与天赋

- 普通攻击使用攻击者的主属性；伤害技能使用技能自身属性，通用无属性技能按中性处理。
- 受击方只以主属性参与克制。副属性用于可学习技能、可装备物品及对应天赋条件，不作为第二层防御倍率。
- 五行：金克木、木克土、土克水、水克火、火克金。特殊关系：风克土、雷克水、毒克木。
- 优势倍率 1.25，受克倍率 0.8，无关系为 1.0。冰继承水的关系，因此冰克火，同时受土、雷克制；不重复叠乘祖先关系。
- 例如三灵鹿主木、副风火，受金系攻击时按木被克制，不会用副火抵消。毕方即使元素列表把风写在前面，普攻仍用明确记录的主属性火。

每种宠物都有天赋神通，无需秘笈，不占携带技能栏。当前包括增伤、首击、吸血、反击、开场护盾、行动回血、残血追击、闪避、毒伤、穿透防御十类效果，具体数值见该宠物图鉴。

增伤倍率在扣除防御之前计算。护盾每场仅在开始时生成；反击不会触发反击链。毒、吸血和受击反击都要求直接攻击实际造成气血损失，护盾完全吸收时不触发。中毒在目标行动前扣血，持续三次行动，再次命中刷新而不叠层，毒伤绕过护盾；战斗结束清除所有临时效果。最多 40 回合，不会无限交战。

## 装备与灵术

```text
灵宠装备图鉴
灵宠购买 青岚翎 1
灵宠装备 青岚翎
灵宠装备
灵宠强化 灵器
灵宠卸装 灵器
灵宠技能图鉴
灵宠购买 风刃术诀 1
灵宠学习 风刃术
灵宠技能
灵宠卸技 风刃术
灵宠携带 风刃术
```

每只宠物有灵器、护甲、饰品三个位置。穿戴从共享背包取走一件，替换或卸装返回背包；一件不能同时给两只宠物穿戴。装备提供固定属性加成，并真正参与 PVE、PVP 和切磋。

强化针对当前宠物已穿戴装备，可填槽位或装备名称，每次升一级，+0 至 +10，固定成功。消耗灵石和锻造材料，当前装备面板列出下一阶成本。每级仅让装备自身的加成增加原始值的 20%，+10 为三倍，不把整只宠物的属性放大。卸装、换宠或重新穿戴保留强化，背包按强化等级分开显示，同名优先穿戴背包中强化最高的一件。

技能学会后永久记在该宠物上，消耗一本对应秘笈；同一技能不会重复学习或消耗。默认最多携带两个，学会更多时保存为未携带状态，卸技只卸下，不遗忘，不返还秘笈。

技能从 1 级开始，最高 5 级。在单人/组队 PVE 和积分论剑中，每次真正施放获得 5 点熟练度，胜败均计；没有行动、未携带的技能、天赋、切磋都不奖励。伤害技能被闪避仍算已经施放；满血时治疗技能回退普攻，不计该技能熟练度。升级依次消耗 20、50、100、180 点熟练度，超额结转，满级后停止积累。等级威力倍率依次为 1、1.12、1.25、1.4、1.6，对伤害与恢复都生效；治疗不超过最大气血。

战斗按已携带技能的固定顺序轮流施展。伤害技能按攻击倍率造成对应元素伤害；恢复技能按最大气血比例回复自己，满气血时改用普通攻击。没有技能时正常普攻；本版没有法力或技能秒数冷却。

技能等级、熟练度属于每只宠物自己的存档，卸技、重新携带、切宠不丢失，也不会自动共享给同种族的其他宠物。战后成长与精力、奖励、消息去重一起提交，同一战报重投不会再次增加熟练度。

装备图鉴、技能图鉴、商店均支持页码或名称查询，每页 5 项，不再一次刷出全部内容。例如 `灵宠技能图鉴 2`、`灵宠技能图鉴 霜封术`、`灵宠商店 锻灵矿`。

## 控制与驱散

六种新增灵术均可从商店购买对应秘笈，再按元素和境界门槛学习：

| 灵术 | 效果 |
| --- | --- |
| 霜封术 | 冰系伤害，附加跳过一次行动的控制 |
| 蚀力毒咒 | 毒系伤害，暂时降低目标攻击 |
| 岩灵护障 | 为自身生成有行动次数期限的护盾 |
| 清心灵息 | 恢复自身，并净化己方负面状态最多的单位 |
| 破障术 | 驱散敌方天赋护盾、临时护盾与攻击增益 |
| 战意灵歌 | 为己方攻击最高且仍可受益的单位增加攻击 |

受控单位跳过一次行动，随后至少获得一次完整行动的免控，不能被快手或多名对手连续锁住。跳过行动也会推进持续效果的剩余次数，但不会推进技能轮换或获得熟练度。被控者不能自行施法净化，需要队友解除。

同类弱化、增益、临时护盾保留较强效果并刷新持续次数，不相加；弱化与增益可共存，分别乘到攻击。普通攻击和反击使用当前有效攻击。临时护盾先于天赋护盾吸收伤害，护盾仍可被驱散，毒伤依旧绕过护盾。

满血治疗若能执行有效净化，仍会施放并计熟练度；没有可恢复气血、可净化状态或可施加效果时，回退主属性普攻，不算该技能施放。控制、弱化、驱散可被闪避，伤害附加效果仅命中时生效；所有状态战后清空。

## 打造与分解

```text
灵宠工坊
灵宠工坊 青岚翎 +3
灵宠打造 青岚翎 2
灵宠分解 青岚翎 1
灵宠分解 青岚翎 +3 1
```

工坊覆盖全部 14 件装备，显示精确打造成本和指定强化等级的回收量。打造消耗灵石和材料，获得 +0 装备，数量为 1-99。装备适用限制在穿戴时检查，不能用打造绕过元素、类别和境界门槛。

分解只消耗背包中的指定装备，不会自动拆掉穿戴中的装备。不填强化等级时只分解 +0，强化件必须明确写 `+N`。回收基础材料加累计强化材料的至多 50%，按每件、每种材料向下取整；不退还任何打造或强化灵石。高等级材料不会按多件合并后多返，反复打造、强化、分解不能复制材料。
