# 玩法说明

命令可带 `/`，也可不带。参数前留空格。QQ 群内一般先 @机器人，按钮由点击者自己的身份执行。两端 ID 不同就是不同玩家，不做绑定。

## 结契与灵宠

| 指令 | 作用 |
| --- | --- |
| 灵宠领养 青鸾 | 首次结契，可选青鸾、玄狐、白泽、蛟龙；不填名称则随机初始种族 |
| 灵宠召唤 1 | 每次 100 灵石，支持 1-10 次，概率见图鉴 |
| 灵宠列表 1 | 每页 5 只，显示实例编号；星号为当前出战宠物 |
| 灵宠切换 2 | 用列表中的编号切换，同名多宠必须用编号 |
| 我的灵宠 | 查看境界层数、血脉、属性、资源和下一阶段要求 |
| 灵宠改名 小青 | 1-12 个汉字、字母或数字 |
| 灵宠图鉴 1 / 灵宠图鉴 毕方 | 分页浏览，或查看指定种族的主副属性、天赋和获取途径 |
| 灵宠使用 灵卵名称 1 | 消耗秘境掉落的灵卵，孵化对应种族的新宠 |
| 我的道号 | 查看自己的唯一道号 |
| 灵宠道号 听雨散人 | 修改道号，2-12 个汉字、字母或数字，全服不可重复 |

结契时从道号词库随机生成唯一道号，冲突时自动另取；字母大小写不产生两个相同道号。原始 ID 只用于后台区分人物，不显示给玩家，不作为交互参数。改道号不影响已经发起的邀请、队伍或存档。

初始选择固定为青鸾、玄狐、白泽、蛟龙，不会随着图鉴扩充而增加。目前共 27 种灵宠，其他种族通过召唤或秘境灵卵获得。灵卵孵化前会检查容量，不足时不消耗；孵化不会自动切换出战宠物。每只灵宠独立成长，共用玩家的灵石、背包、任务与行动冷却，默认最多 50 只。

青鸾偏修炼与风系增伤，玄狐偏首击突袭，白泽带开场护盾，蛟龙擅长破甲。同元素也有不同定位，例如火系玄狐抢攻、毕方强化火系威力、赤焰虎追击残血、熔岩甲受击反震，不是仅替换名称的同一套数值。

## 成长与进化

大境界：启灵 → 凝气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫，每个境界一至十层。

| 指令 | 规则 |
| --- | --- |
| 灵宠签到 | 北京时间每日 00:00 刷新，默认 200 灵石、3 份灵粮 |
| 灵宠喂养 | 使用 1 份灵粮，精力 +20、修为 +10、亲密 +5 |
| 灵宠修炼 | 默认消耗 15 精力，冷却 300 秒，按种族与大境界获得修为 |
| 灵宠突破 | 一至九层为小境界突破；十层为大境界破境，成功后进入下一境界一层 |
| 灵宠突破 破境丹 | 大境界破境时额外消耗 1 丹，增加 10 个百分点成功率 |
| 灵宠进化 | 消耗面板显示的修为、灵石、血脉精华，独立提升血脉等级 |

小境界默认必成。大境界失败不降级，但消耗本次全部灵石、已用道具与要求修为的四分之一。血脉为凡血、灵血、玄血、真血、仙血，默认进化必成并增强属性。自定义内容调整概率时，进化失败仍消耗本次全部进化成本。

修为是可花费的资源，不直接等于战斗力。战斗属性由种族、境界、层数、血脉和亲密决定。精力上限 100，默认每 300 秒恢复 1 点，离线恢复无需后台计时器。切换宠物不会重置玩家冷却。

## 物品与任务

```text
灵宠背包
灵宠商店
灵宠购买 灵粮 3
灵宠使用 回元丹 1
灵宠任务
灵宠领奖 吐纳一周天
```

数量为 1-99 的整数。材料不能直接服用；纯恢复道具在相应属性已满时不会扣除。批量使用会按数量生效，超过上限的恢复量会溢出，请按需使用。

任务默认包括修炼、喂养、历练和 PVE 胜利，每日重新计数，每项每天领取一次。名称和奖励可在“灵宠任务”查看，跨日不保留未领取奖励。

## 单人 PVE

```text
灵宠历练
灵宠秘境
灵宠挑战 青岚林
```

历练是随机奇遇，消耗 25 精力，默认冷却 900 秒。秘境是实际回合战斗，青岚林从启灵开放，月影谷从凝气开放，雷泽从筑基开放；准入境界不代表一定获胜。

战斗最多 40 回合，所有参战单位从满气血开始，气血仅属于本场，不需要持久化治疗。胜利获得修为、灵石和秘境对应的材料、灵卵；败退或平局没有胜利奖励，但实际施放的技能仍获得熟练度。无论胜败均消耗精力并进入 PVE 冷却，单人和组队秘境默认共享 600 秒冷却。

## PVP 与切磋

同一会话中双方先用“我的道号”查看道号，然后：

```text
灵宠论剑 对方道号
灵宠应战
```

- 只有被邀请者能应战。邀请默认 300 秒有效，每位玩家同时只参与一个待处理邀请。
- 发起后不立即扣费。应战时用双方当前出战灵宠和属性，重新检查精力与冷却，一次事务结算。
- 默认每人消耗 20 精力，900 秒论剑冷却；胜方 +20 积分、败方 -20，败方积分不足时以余额为限，平局不改积分。
- 同一对玩家每天最多结算一次论剑积分；顺序调换也不能重复结算，不发放灵石/修为/道具奖励。
- 结果回复到应战发生的会话，不主动跨群通知。建议双方在同一会话操作。

使用 `灵宠切磋 对方道号` 发起无损对战，仍需对方应战，但不消耗精力、不计积分、不发奖励或技能熟练度。任一方发送 `灵宠拒战` 可拒绝或撤回邀请。

`灵宠论剑榜` 查看积分榜；`灵宠排行` 每人取境界最高的一只宠物入榜，不因收藏大量宠物占满排行。

## 组队 PVE

1. 队长发送 `灵宠组队`，得到队伍编号。
2. 队员发送 `灵宠入队 队长道号` 或 `灵宠入队 队伍编号`，默认最多三人，同一玩家不能加入多队。参数与已有道号完全相同时，优先按队长道号解释。
3. 每人发送 `灵宠准备`，同意下一次组队战斗消耗当前灵宠的精力和 PVE 冷却。
4. 队长发送 `灵宠组队挑战 上古灵殿`，至少两人、全员准备且满足准入与资源要求才能开始。
5. 胜利后每位成员获得一份独立奖励；战后全员取消准备，下次须重新准备。

`灵宠队伍` 查看成员道号；`灵宠取消准备` 撤回出征意愿；`灵宠退队` 离开。队长退出时队伍解散。切宠、修炼、历练、进化、突破、服用道具、变更装备/技能或进行消耗精力的战斗，会取消自己的准备状态。

一人资源不足时整个挑战不扣费，不会先扣队友资源。无需同时在线，但必须提前明确准备。上古灵殿从启灵开放，幽冥深渊从筑基开放；提高层数、血脉或凑齐三人更容易战胜敌人。

## 类别与元素

| 灵宠示例 | 类别 | 主属性 | 副属性 |
| --- | --- | --- | --- |
| 青鸾 | 羽族 | 风 | 木 |
| 玄狐 | 兽族 | 火 | 无 |
| 白泽 | 兽族 | 金 | 土 |
| 蛟龙 | 龙族 | 水 | 雷 |
| 毕方 | 羽族 | 火 | 风 |
| 玄武 | 甲族 | 水 | 土 |
| 三灵鹿 | 兽族 | 木 | 风、火 |
| 寒翎鹰 | 羽族 | 冰 | 风 |
| 玄冰蚕 | 虫族 | 冰 | 无 |
| 青藤灵 | 植族 | 木 | 无 |
| 碧竹蛇 | 蛇族 | 木 | 毒 |
| 岩心偶 | 灵族 | 土 | 无 |

类别和元素是不同维度。技能或装备可以同时要求境界、类别与元素；全部条件都满足才可使用。例如玄狐不能学习水箭术，三灵鹿可以学习风刃术、赤焰术和青木回春；风火燎原要求同时具备风、火并达到凝气，不是任意满足其中一个。

龙鳞甲仅限龙族；雷霆吐息要求龙族且具备雷系。学习和携带都会检查，不能先在别的宠物上学习再通过切宠共享技能。

冰是水的分支：冰宠可满足水系技能、装备的元素条件，但只有水属性的宠物不能学习冰系专属术法。类别与境界门槛仍须满足。风、雷、毒为独立特殊元素，不因名称或现实联想自动归入某个五行。

## 属性克制与天赋

- 普通攻击使用攻击者的主属性；伤害技能使用技能自身属性，通用无属性技能按中性处理。
- 受击方只以主属性参与克制。副属性用于可学习技能、可装备物品及对应天赋条件，不作为第二层防御倍率。
- 五行：金克木、木克土、土克水、水克火、火克金。特殊关系：风克土、雷克水、毒克木。
- 优势倍率 1.25，受克倍率 0.8，无关系为 1.0。冰继承水的关系，因此冰克火，同时受土、雷克制；不重复叠乘祖先关系。
- 例如三灵鹿主木、副风火，受金系攻击时按木被克制，不会用副火抵消。毕方即使元素列表把风写在前面，普攻仍用明确记录的主属性火。

每种宠物都有天赋神通，无需秘笈，不占携带技能栏。当前包括增伤、首击、吸血、反击、开场护盾、行动回血、残血追击、闪避、毒伤、穿透防御十类效果，具体数值见该宠物图鉴。

增伤倍率在扣除防御之前计算。护盾每场仅在开始时生成；反击不会触发反击链。毒、吸血和受击反击都要求直接攻击实际造成气血损失，护盾完全吸收时不触发。中毒在目标行动前扣血，持续三次行动，再次命中刷新而不叠层，毒伤绕过护盾；战斗结束清除所有临时效果。最多 40 回合，不会无限交战。

## 装备与灵术

```text
灵宠装备图鉴
灵宠购买 青岚翎 1
灵宠装备 青岚翎
灵宠装备
灵宠强化 灵器
灵宠卸装 灵器
灵宠技能图鉴
灵宠购买 风刃术诀 1
灵宠学习 风刃术
灵宠技能
灵宠卸技 风刃术
灵宠携带 风刃术
```

每只宠物有灵器、护甲、饰品三个位置。穿戴从共享背包取走一件，替换或卸装返回背包；一件不能同时给两只宠物穿戴。装备提供固定属性加成，并真正参与 PVE、PVP 和切磋。

强化针对当前宠物已穿戴装备，可填槽位或装备名称，每次升一级，+0 至 +10，固定成功。消耗灵石和锻造材料，当前装备面板列出下一阶成本。每级仅让装备自身的加成增加原始值的 20%，+10 为三倍，不把整只宠物的属性放大。卸装、换宠或重新穿戴保留强化，背包按强化等级分开显示，同名优先穿戴背包中强化最高的一件。

技能学会后永久记在该宠物上，消耗一本对应秘笈；同一技能不会重复学习或消耗。默认最多携带两个，学会更多时保存为未携带状态，卸技只卸下，不遗忘，不返还秘笈。

技能从 1 级开始，最高 5 级。在单人/组队 PVE 和积分论剑中，每次真正施放获得 5 点熟练度，胜败均计；没有行动、未携带的技能、天赋、切磋都不奖励。伤害技能被闪避仍算已经施放；满血时治疗技能回退普攻，不计该技能熟练度。升级依次消耗 20、50、100、180 点熟练度，超额结转，满级后停止积累。等级威力倍率依次为 1、1.12、1.25、1.4、1.6，对伤害与恢复都生效；治疗不超过最大气血。

战斗按已携带技能的固定顺序轮流施展。伤害技能按攻击倍率造成对应元素伤害；恢复技能按最大气血比例回复自己，满气血时改用普通攻击。没有技能时正常普攻；本版没有法力或技能秒数冷却。

技能等级、熟练度属于每只宠物自己的存档，卸技、重新携带、切宠不丢失，也不会自动共享给同种族的其他宠物。战后成长与精力、奖励、消息去重一起提交，同一战报重投不会再次增加熟练度。
