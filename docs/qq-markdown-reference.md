# QQ Markdown 与交互

QQ 官方机器人的 Markdown、蓝字和键盘按钮取决于消息模式、平台权限与客户端支持。接入和模式配置见[连接机器人](CONNECTIONS.md)。

## 消息模式

- `text`：发送普通文本，可手动输入页面列出的命令。
- `native`：发送原生 Markdown；开启 `SPIRIT_PET_QQ_BLUE_LINKS` 后，正文入口可填入或发送命令。
- `template`：使用审核通过的模板及其参数，呈现效果由模板决定。

`SPIRIT_PET_QQ_KEYBOARD` 控制富消息键盘。每页最多四个主要按钮，详情和逐项动作放在正文蓝字中；帮助页面按分类提供正文入口。没有对应权限时，普通文本命令仍可使用。

## 常用语法

````markdown
# 标题
**加粗**
_斜体_
~~删除线~~

[链接](https://qun.qq.com)

1. 有序项
2. 下一项

- 无序项
- 下一项

> 引用

---

| 项目 | 数值 |
| --- | --- |
| 气血 | 100 |

```text
灵宠帮助
```

$$
E=mc^2
$$
````

表格可用于签到月历与属性对比。代码块中的命令需要手动输入，不能直接点击执行；蓝字放在代码块之外。图片需要有效的图片地址与相应媒体发送权限。

## 蓝字与按钮

蓝字可直接发送完整动作，也可先填入需要补全参数的命令。命令前缀由 `SPIRIT_PET_COMMAND_PREFIX` 决定，默认 `/`；无前缀完整中文命令始终可用。

键盘按钮与正文蓝字是两种独立的消息能力；开启 Markdown 不代表自动获得键盘权限。点击动作以点击者身份执行，仍会检查自己的伙伴、资源和操作资格。

## 排错

1. 核对 `SPIRIT_PET_QQ_MODE`、模板 ID 和参数名，修改后重启实例。
2. 确认开放平台已授权原生 Markdown、模板或自定义键盘，以及当前会话所需的消息事件。
3. 检查平台返回码与日志中的回退原因；普通文本回退成功只代表消息送达。
4. 在实际 QQ 客户端检查表格、蓝字和按钮；OneBot 的文本呈现不能代表 QQ 客户端效果。
