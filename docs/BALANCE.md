# 数值验收

本阶段的目标是让七个境界都有可用的单人、双人和三人资源秘境，并验证准备后的常见阵容存在胜利路径、效果有明确期限、材料循环不会增殖。不是声明所有 PVP 配装均已竞技平衡。

## 复现

在仓库根目录使用已安装依赖的环境：

```bash
$HOME/myenv/bin/python scripts/balance_report.py --runs 100 --seed 20261007 --csv docs/reports/balance.csv --check
```

Linux/Windows 使用自己的虚拟环境解释器。`--output 路径.json` 可额外输出完整 JSON，包括每只参战宠物实际属性和所带技能。所有战斗使用临时 SQLite，场景构建后回滚，不会连接真实玩家数据库。脚本复用生产环境的适用检查、装备/技能组装和实际战斗算法，不是另一套近似战斗公式。

每个场景的种子由总种子与稳定场景 ID 派生，所以调换场景执行顺序不会改变结果。报告输出已加载 Catalog 的 SHA-256，而不是把未实际参与模拟的文件版本当作证据。

## 场景范围

- 16 个秘境全部覆盖，七个境界都包含单人和组队内容。
- 单人包含全部 27 种灵宠；组队包含四个初选种族的相邻双人/三人组合，以及火系双人、水系三人组合，每个组队秘境 10 个阵容。
- entry：准入大境界一层、凡血、初始亲密、无装备和技能。用于观察刚解锁的难度，不要求必胜。
- prepared：同境界五层、血脉等级为大境界序号整除二、亲密 30、三槽兼容装备强化至大境界序号、一个伤害和一个恢复技能，技能等级为 1 加大境界序号整除二。选择按固定数值评分，不依赖某次战斗结果。
- prepared 不选择血脉分支，避免把不可逆选择作为普通资源副本获胜的前提。54 条分支另有下述配对专项仿真及成本、取舍、实际属性和装备独立性集成测试。
- 控制、净化、驱散等辅助配装另有下述真实触发专项仿真；回合边界、双人轮控与真实 PVE/PVP 结算由主动效果测试覆盖，不把固定配装矩阵冒称为全配装穷举。

## 收益口径

所有收益按每位玩家计算。每次挑战的期望修为/灵石为奖励区间均值乘采样胜率；败退、平局不发胜利奖励。

持续挑战间隔取 `max(PVE 冷却, 单次精力成本 × 自然恢复间隔)`，再计算每小时收益。不能只按 600 秒冷却计算收益而忽略精力恢复。默认青岚林一次消耗 20 精力，自然恢复需要 6000 秒，因此持续挑战为每小时 0.6 次，而不是 6 次。

这个指标不计开局满精力、药品、签到、每日任务、其他行动的精力占用或装备材料的售价，也不冒称在线时长收益或完整经济通胀预测。组队掉落每人独立，不拿全队总奖励充当个人收益。

## 分支与主动效果专项

```bash
$HOME/myenv/bin/python scripts/balance_specials.py --runs 100 --seed 20261007 --csv docs/reports/balance_specials.csv --check
```

可用 `--output 路径.json` 保存完整结果，包含参战四维、主属性、技能属性、实际克制倍率、触发次数和覆盖审计。专项使用独立临时数据库，不改变原 626 个基线场景、基础报告或游戏数值。

- 血脉：54 条分支各有选中与未选中对照，共 108 个场景。使用同种族、筑基五层、该分支要求的最低血脉（当前均为灵血）、亲密、装备和技能，与真实筑基单人秘境对战。只改变分支，假设觉醒成本已支付，不制造不符合种族或血脉门槛的状态。
- 效果：6 个技能各有携带该技能与仅普攻的对照，共 12 个场景。使用实际最低学习境界、兼容宠物、生产装备和神通；非法境界、类别、元素仍由生产检查拒绝。冰系对火系场景明确验证水分支继承的 1.25 倍克制。
- 清心灵息为双人合成夹具，开场预置敌方毒神通造成的一次合法 1 点气血命中，提供确定的友方净化机会；破障术面对具有初始护盾的白泽。其余状态不提前授予，不把所有辅助配装预设为必胜。
- 实际生效计数必须同时满足生产 `effects.apply` 返回事件、对应目标状态确实改变。仅携带、规划目标或记下一次施放均不算覆盖；免控、无有效目标、死亡或被闪避的效果不会冒充成功。
- 观察器仅在隔离、单进程专项工具的上下文中包装生产函数，正常结束和异常退出均恢复原函数。测试验证专项前后同一种子基础仿真结果一致，不应把该观察器装进运行中的机器人。
- 配对场景共享稳定种子组；同种族两条分支的未选中对照参数相同，CSV 中重复保留便于逐条比较，不将这些重复对照冒充独立统计样本。

结果：[balance_specials.csv](reports/balance_specials.csv)。种子 `20261007`，Catalog 哈希与上方基线一致，120 个场景各 100 次，共 12,000 场战斗。54/54 条分支均通过生产装配产生实际属性变化并参战，6/6 个主动技能效果均实际触发；未发现越过 40 回合或非法气血的样本。54 个分支选中组共 5,400 胜、0 平、0 败，最长 16 回合。

这些结果不隐藏不利样本：仅携带岩盾的防守配装能拖成平局，但没有进攻能力；清心配装虽把平均存活回合从 8.42 延长至 16.33，仍未获胜；驱散和增益在本固定配装中也未改变胜负。专项门禁检查覆盖、实际触发、配对对照和回合边界，不将「全部配装获胜」设为通过条件。

这仍不是完整竞技平衡证明：未穷举全种族 PVP、全部技能组合、分支互斗、跨境界、每个技能等级及长期玩家策略；也不计算觉醒/购买耗时、通胀或辅助技能的经济收益。上述范围在完整 JSON 的 `scope.not_covered` 中保留，不能用专项绿灯替代后续实际运营数据。
